# Authentication System (PHP)

This is a simple authentication system built using PHP and MySQL.

## Features
- User registration
- User login and logout
- Admin and user pages
- Database connection using PHP
- Form handling and session management

## Technologies Used
- HTML
- CSS
- PHP
- MySQL (XAMPP)

## Description
This project demonstrates basic user authentication and database interaction using PHP. It includes login and registration functionality and separates user and admin access.
